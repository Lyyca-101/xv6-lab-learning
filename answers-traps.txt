1.Which registers contain arguments to functions? 
For example, which register holds 13 in main's call to printf?
answer:according to riscv calling convention,register a0-a7 will contain arguments to
functions,and a0 will also store the return value of the function.
according to the call.asm,register a2 holds 13 in main's call to printf.

5.Run the following code.

	unsigned int i = 0x00646c72;
	printf("H%x Wo%s", 57616, &i);
      
What is the output? Here's an ASCII table that maps bytes to characters.
The output depends on that fact that the RISC-V is little-endian.
If the RISC-V were instead big-endian what would you set i to in order to yield the same output?
Would you need to change 57616 to a different value?
answer:the output is "HE110 World",the format specifier %x makes 57616 to its hex form,
which is e110,the "e" is uppercase in the output.Because RISC-V is little-endian,
so in memory,the value i can be seemed as 0x72 0x6c 0x64 0x00 from low address to high
address,the same as a char array ['r','l','d','\0'],0x72 is r,0x6c is l,0x64 is d,0x00
is \0,according to ASCII Table.
If RISC-V is big-endian,then set unsigned int i = 0x726c6400,because most significant byte is
stored in lowest address.There is no need to change 57616 to a different value,since e110
is just its hex form.
